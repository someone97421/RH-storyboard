# 任务分类标签 (Triage labels)

**【全局指令】**：在处理此代码库的所有任务时，智能体**必须**使用中文进行内部思考、对话和交流。

在对 Issue 进行分类处理时，智能体必须使用以下 GitHub 标签来对应标准的分类状态：

- `needs-triage` -> `needs-triage` (需要维护者进行评估)
- `needs-info` -> `needs-info` (等待问题报告者提供信息)
- `ready-for-agent` -> `ready-for-agent` (需求完全明确，已准备好由 AI 智能体接手)
- `ready-for-human` -> `ready-for-human` (需要人类开发者亲自实现)
- `wontfix` -> `wontfix` (暂不处理或不予修复)
